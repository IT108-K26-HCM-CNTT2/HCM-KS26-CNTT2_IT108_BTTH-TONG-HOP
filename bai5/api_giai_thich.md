# Tài liệu tra cứu: API

## 1. Prompt hỏi AI
## Tôi là ai / Bối cảnh
Tôi là sinh viên năm nhất mới tham gia nhóm dự án SmartCampus, đang học về các thuật ngữ kỹ thuật cơ bản.

## Chủ đề / Nội dung cần xử lý
Giải thích thuật ngữ: API (Application Programming Interface).

## Yêu cầu
- Giải thích API bằng ví dụ thực tế đơn giản, dễ hiểu.
- Nêu vai trò của API đối với app di động (như việc lấy dữ liệu lịch học).
- Trình bày ngắn gọn, chia thành các gạch đầu dòng rõ ràng.

## Không cần
- Không giải thích mã nguồn phức tạp hay thuật toán nâng cao.

---

## 2. Tóm tắt khái niệm API
API đóng vai trò như một cầu nối giúp ứng dụng di động gửi yêu cầu và lấy dữ liệu từ máy chủ về hiển thị cho người dùng. Trong ứng dụng SmartCampus, API giúp app kết nối trực tiếp với hệ thống nhà trường để lấy thông tin lịch học và phòng trống. Nhờ có API, việc truyền nhận dữ liệu giữa app và server diễn ra nhanh chóng, chính xác và an toàn.
