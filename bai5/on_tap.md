# Bẫy cú pháp Markdown (Phần 4)

## 1. Chỉ ra 2 lỗi cú pháp
- **Lỗi 1 (Table):** Thiếu dòng phân cách cột |---|---| ngay bên dưới dòng tiêu đề bảng.
- **Lỗi 2 (Task List):** Thiếu khoảng trắng (space) sau dấu gạch ngang (-). Bạn đó viết liền -[x] và -[ ] nên hệ thống không nhận diện được danh sách công việc.

## 2. Đoạn Markdown đã sửa chuẩn
| Tính năng | Trạng thái |
| :--- | :--- |
| Tra cứu lịch học | Xong |
| Push notification | Đang làm |

- [x] Tra cứu lịch học
- [ ] Push notification
