PHẦN 4 – XỬ LÝ LỖI

Câu 9:
Nguyên nhân: Gõ sai tên thư mục, dùng scr thay vì src.
Khắc phục: Gõ cd rồi nhấn Tab để tìm tên thư mục đúng.

Câu 10:
Nguyên nhân: Không đủ quyền truy cập hoặc file script bị chặn.
Khắc phục: Kiểm tra file và quyền truy cập. Nếu file đáng tin, thử:

.\setup.ps1

Câu 11:
Nguyên nhân: Thư mục old-version còn chứa file nên PowerShell hỏi xác nhận.

Lệnh xóa:
Remove-Item .\old-version -Recurse -Force
