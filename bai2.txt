

PHẦN 1 - KIẾN TRÚC HỆ ĐIỀU HÀNH

1. Chức năng của hệ điều hành
Đây là chức năng quản lý tiến trình và tài nguyên. Hệ điều hành phân chia CPU, RAM cho Word, Chrome, VS Code và Portal để các phần mềm chạy đồng thời. Nếu thiếu tài nguyên, máy tính có thể bị chậm.

2. Shell và Kernel
Khi double-click file, người dùng tương tác trước với Shell thông qua File Explorer. Shell tiếp nhận thao tác và yêu cầu mở file, còn Kernel quản lý tài nguyên và thực hiện các hoạt động hệ thống cần thiết. Người dùng ít tương tác trực tiếp với Kernel vì đây là phần lõi của hệ điều hành.

PHẦN 6 - ĐUÔI FILE VÀ FILE ẨN

1. Nhận diện file đáng ngờ
File hiển thị de-thi-dap-an.pdf có thể thực chất là de-thi-dap-an.pdf.exe. Kẻ xấu có thể lợi dụng việc Windows ẩn phần mở rộng để giả dạng file PDF.

Cách kiểm tra:
1. Mở File Explorer.
2. Chọn View -> Show -> File name extensions.
3. Kiểm tra phần mở rộng thật của file.

Vì file được tải từ link lạ trên Zalo, không mở file. Hãy xác minh nguồn gửi và quét bằng Windows Security; nếu không xác minh được, nên xóa file.
